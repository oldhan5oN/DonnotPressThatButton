# 《别按那个键》—— 程序模块清单与项目规模规划

> 依据 `Assets/清单/玩法流程.txt` 与需求访谈整理，作为程序开发总蓝图。

## 一、项目背景

项目当前**玩法代码近乎空白**：仅有一套已完成的 URP 复古后处理特效（`RetroEffectRendererFeature` / `RetroEffectVolumeComponent`）和材质重建编辑器工具；`PlayerController.cs` 只在按空格时播一段死亡动画，交互 / UI / 资源 / 状态系统全无。美术侧资产较齐（士兵角色、步枪、太空舱模型且材质已重建），URP 17.3 + Input System 1.18 已就位但未接线。

## 二、已确认的核心设计

- **主题**：「别按那个键」。**电量（初始 15%）是唯一硬预算**，所有动作共用这笔电：制氧 3% / 电击恢复状态 2% / 解锁舱门 1% / **广播 10%**。
- **三条抉择张力**（资源稀缺驱动的道德选择）：
  1. 死前广播留信息（耗 10% 电、几乎宣判己死）；
  2. 把电用于氧气 / 电击苟活、换时间读散落笔记（但失去广播资格）；
  3. 状态过低被字幕怂恿、开右门跳入宇宙自杀解脱。
- **视点**：第一人称自由移动（WASD + 鼠标），屏幕中心射线对准按 F 交互。
- **死亡演出**：第一人称黑屏 + 音效（不切第三人称，士兵死亡动画 / Ragdoll 本版不用）。
- **打字小游戏**：首字母逐字映射（如「没」→ M），屏幕虚拟键盘鼠标点击；先逐字打完整段广播文本（错按显 `*` 不阻断）→ 开玻璃罩 → 按广播 → 扣 10% → 成功；**短路键点到即失败**。
- **流程控制**：全局状态机 + 软引导（资源衰减与字幕施压，非强制线性解锁）。
- **视觉扭曲**：新建独立扭曲后处理 Pass，由精神值驱动（参考但不复用 RetroEffect）。
- **字幕旁白**：轻量字幕系统（打字机效果、无配音、SO 配置文本）。
- **场景**：程序负责用太空舱 FBX 搭出「可玩布局」（休眠舱 + 设备室两房间、设备 / 门 / 广播柱摆放、基础灯光与碰撞）。
- **外围**：音频管理器 + 极简主菜单 + 设置面板（音量 / 鼠标灵敏度）；**不做存档**。
- 止痛剂作废，精神由「开氧气 + 用电击」维持（均耗电）。

## 三、项目规模判断

**小型第一人称叙事解谜（步行模拟器 + 资源管理）**，单场景、单周目、约 10–20 分钟体验。预估程序脚本 **30–40 个**、ScriptableObject 数据资产若干，外加一个新的 URP RendererFeature。属「单人数周可完成」量级，复杂度集中在**终端打字子系统**与**资源—状态—结局耦合**两处。

## 四、程序模块清单（分层 + 设计模式标注）

### L0 输入与工程框架
- **InputActions 资产**：Move / Look / Interact(F) / Click(鼠标) / Pause(Esc)。接通 Input System。
- 命名空间 / 目录规范（`Assets/Scripts` 下按层分目录）。

### L1 玩家与相机
- **`FirstPersonController`**：基于 `CharacterController` 的 WASD 移动 + 鼠标 look + 头部高度；死亡 / 暂停时锁输入。（替换现有占位 `PlayerController.cs`）
- 玩家相机挂点（准星射线源）。

### L2 交互系统（核心架构）
- **`IInteractable` 接口** + **`InteractableBase` 抽象基类**。
  - 设计模式：**面向接口编程 / 开闭原则（OCP）** + **模板方法（Template Method）**——新增设备不改核心。
- **`InteractionRaycaster`**：屏幕中心射线探测可交互物，驱动准星高亮 / 提示文字，按 F 触发。
- 各设备交互组件（均继承基类）：制氧机、神经电击器、电力分配终端、电脑终端、日记本、广播按钮柱、右门开门按钮。

### L3 资源系统（单一数据源）
- **`ResourceSystem`**：电能 / 氧气 / 精神三值；时间驱动衰减；耦合规则（氧气低 → 精神加速下降；电击 / 制氧回升）。
  - 设计模式：**观察者模式（Observer）**——通过事件通知 HUD / 字幕 / 特效，避免轮询耦合。
- **统一耗电 API** `TrySpendPower(cost)`：所有设备走此入口（便于失败判定与数值集中）。
- **`ResourceConfig`（ScriptableObject）**：初始值、衰减速率、各动作消耗——**数据驱动**便于调参。

### L4 游戏流程状态机
- **`GameManager` / `GameStateMachine`**：进行中 / 失败 / 成功。
  - 设计模式：**状态模式（State）**。
- 失败态处理：停衰减、精神恢复、放开读日记、字幕引导自杀；成功态：电源渐暗 → 结束。
- 结局分发：广播成功结局、跳门自杀结局、低电 / 短路失败后自杀结局。

### L5 UI 系统
- **`UIManager`**：面板栈、打开 / 关闭、暂停与鼠标锁定切换。设计模式：**中介者（Mediator）/ 栈式管理**。
- **`HUD`**：电能 / 氧气 / 精神条 + 准星 + 交互提示。订阅 `ResourceSystem`（观察者）。
- 设备弹窗 UI：通用「确认按钮 + 耗电提示」面板（制氧 / 电击 / 解锁复用），电击把手交互 UI。
- **日记 UI**：阅读 / 翻页，支持多篇散落笔记（数据 SO）。
- **`SubtitleSystem`**：字幕队列 + 打字机效果，数据 SO 配置。
- 极简主菜单 + 设置面板（音量、鼠标灵敏度）+ 暂停菜单。

### L6 终端打字子系统（最复杂，独立）
- **`TerminalScreen`**：待打汉字序列、目标字母、低透明度提示态、错按显 `*`、进度。
- **`VirtualKeyboard`**：屏幕 26 键虚拟键盘，鼠标点击；随时间将若干键标记为「短路键」。
- **`TypingController`**：首字母映射校验、推进、错误处理、短路键触发失败。设计模式：数据 / 视图 / 控制分离（**MVC 风格**）。
- **`BroadcastButton`**：玻璃罩开合 + 广播确认，校验文本完成 → 扣 10% → 触发成功结局。
- **`TerminalData`（ScriptableObject）**：广播全文 + 每字目标字母映射。

### L7 表现与特效
- **`MentalDistortion` 后处理**：新建 `DistortionRendererFeature` + `DistortionVolumeComponent`（独立 URP Pass），强度由精神值驱动。参考现有 `RetroEffectRendererFeature` 实现范式。
- **死亡黑屏演出**：淡入黑屏 + 音效 + 收尾，配合状态机结局。
- 设备音效 / 灯光反馈挂点（制氧气压表变化、开锁、广播等）。

### L8 音频
- **`AudioManager`**：统一播放 SFX（制氧 / 开锁 / 广播 / 按键 / 死亡）与环境底噪。设计模式：**单例 / 服务定位**（轻量）。

### L9 世界 / 场景搭建（程序负责，可玩布局粒度）
- 用太空舱 FBX 搭休眠舱 + 设备室两房间；摆放四台设备、日记本、左 / 右门、广播柱；基础灯光与碰撞体；玩家出生点。
- 在各物体挂对应 L2 交互组件并连数据资产。

### L10 数据资产（ScriptableObject）
- `ResourceConfig`、`TerminalData`、字幕脚本集、日记内容集。**数据与逻辑分离**，便于策划调整。

## 五、建议实现顺序

1. L0 输入 → L1 玩家相机（能走动看世界）
2. L2 交互系统骨架（`IInteractable` + 射线 + 准星）
3. L3 资源系统 + L5 HUD（数值跑起来、可视化）
4. L4 状态机（三结局骨架）
5. 设备交互逐个接入（制氧 / 电击 / 电力终端 / 右门）+ 通用弹窗 UI
6. L6 终端打字子系统（独立开发、最耗时）
7. L5 字幕系统 + 日记 UI
8. L7 精神扭曲 Pass + 死亡黑屏 + L8 音频
9. L9 场景搭建与挂载、L10 数据填充、整体串联
10. 外围：主菜单 / 设置 / 暂停

## 六、验证方式（端到端）

在 `SampleScene` 中分别跑通三条路径：
- **广播结局**：制氧保命 → 终端逐字打完 → 开罩广播（电从 15% → 约 2%）→ 电源渐暗、成功结束。
- **苟活读信**：反复制氧 / 电击耗电 → 电量不足以广播 → 能读完散落笔记、但无法触发广播结局。
- **失败 / 自杀**：触发短路键 **或** 电能跌破 10% → 进入失败态（精神恢复、字幕怂恿）→ 开右门 → 黑屏死亡演出。

同时检查：HUD 三条资源实时随时间 / 操作变化；精神低时屏幕扭曲增强、打字概率出错；主菜单可开始、设置可调音量与灵敏度、Esc 暂停。
